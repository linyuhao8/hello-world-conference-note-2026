# 用 AI 工作流重整事件驅動交易系統的一致性、效能與監測

- 時間：2026-10-14 13:30–14:00
- 講師：蔡宜庭 (ET)
- 公司／職位：國泰金控／工程師

## 官方課程簡介

本場分享如何使用 AI 協作工作流，重整一個以 Java、Spring Boot、RabbitMQ、PostgreSQL 和 Redis Lua 建構的事件驅動交易系統。內容聚焦訊息重送的冪等性、跨服務最終一致性、Outbox 成本、Queue backlog、可觀測性，以及如何用測試、壓測、指標和正確性檢查驗證 AI 建議是否真的有效。
