## 官方課程簡介

本場分享從 LangGraph Agentic RAG 的實作經驗出發，說明企業知識問答的問題不只在檢索流程，也在於原本為人類閱讀的文件對 LLM 不容易理解、引用和維護。課程將介紹 LLM Wiki 的概念，以及如何重新整理文件結構、metadata、來源、版本和更新流程，並討論權限、token 成本與回答品質。
