# 當架構設計被 AI 加速後，工程判斷力的養成與傳承該怎麼辦？

- 日期：2026-10-14
- 時間：17:00–17:30
- 講師：林承毅 (Jed)
- 公司／職位：躍準科技有限公司／Founder
- 地點：BC 會議室
- 課程類型：Session

## 官方課程簡介

Agentic coding 讓架構設計從幾天縮短到幾小時，但也可能壓縮理解脈絡和比較方案的過程。這場分享討論如何依照做錯後回頭的代價，判斷哪些決策交給 AI、哪些決策留給人；並介紹「人先設計、AI 後提案」以及在設計評審中說明被否決方案的做法，讓資深者的判斷能被看見並傳給團隊。
