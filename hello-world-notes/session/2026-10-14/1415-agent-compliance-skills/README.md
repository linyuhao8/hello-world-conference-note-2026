## 官方課程簡介

本場分享如何在受監管的金融環境中，把命名、資源設定、API 存取控管和部署流程等行內規範整理成 Agent 可以呼叫和重複使用的 Skill。內容也會說明為什麼安全邊界要放在 framework、權限和 pre-tool hook，而不能只靠 prompt，並討論哪些低風險動作可以自動化、哪些不可逆動作仍要人工確認。
