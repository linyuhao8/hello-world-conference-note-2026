## 官方課程簡介

把 Coding Agent 接進 Discord 或 Telegram，不只是把 Prompt 轉送給 headless CLI。實際上還要處理 Session lifecycle、Context、Streaming、工具呼叫、權限、Cancel／Resume，以及不同 Coding CLI 的差異，最後會變成一套 Agent Runtime。

本場介紹 Agent Client Protocol（ACP）如何提供 Client 和 Agent 之間的共通介面，以及 OpenAB 如何串接聊天平台、Session Pool 和 Coding Agent Runtime。目標是讓團隊可以送出任務、持續看見進度、適時介入並驗證結果，不必一直守在 Terminal 前操作。
