## 官方課程簡介

同一個 Prompt 產生的結果可能差很多，問題不一定在模型本身，也可能在模型周圍的系統。這場分享從實際踩坑出發，介紹 Harness Engineering，以及如何針對 AI 不穩定、token 成本高和 context 塞滿等問題，使用 routing、caching、compaction 和 verification gates 等方法改善整體工作環境。
