## 官方課程簡介

只把架構規範寫在 AGENTS.md、Prompt 或文件裡，不能保證 Coding Agent 每次修改都遵守。這場分享介紹如何把架構意圖變成可執行的防護牆：後端使用 golangci-lint、depguard 和 Go Architecture Test，前端使用 dependency-cruiser，限制 package dependency、layer boundary、feature isolation 等違規關係，讓每次修改都必須通過驗證。
