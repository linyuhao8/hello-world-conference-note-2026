PART 3 / SUMMARY

這兩天我真正記住的四件事

從課程案例整理出的工程工作方式

01 / OBSERVE

先把現況看清楚

先看架構、使用量、遙測或資料狀態，再決定下一步。

02 / BOUNDARY

把流程與責任切開

讓每個元件、工具或 Agent 有清楚的責任與交接邊界。

03 / CONTROL

讓行動有邊界

權限、Scope、Policy 與人工核准決定哪些操作可以真的發生。

04 / VERIFY

做完一定要再驗證

用測試、報表、對帳或可追查的證據確認結果。

來源：MY-TAKEAWAYS.md；此頁是跨課程整理，不代表每堂課使用相同方法。
