懂行規的 Agent：把規範變成技能，自動化開發到部署

Agent 執行控制流程

講師：張云姵（Sarah）
講師經驗：玉山銀行智能金融處雲端技術架構師，具 GCP 架構、金融跨機構協作與 AI Agent 工作流程平台的架構及部署自動化經驗。
工具／技術：Skills · Permission System · Pre-tool Hook · Harness · Gitleaks
01 / INPUT

使用者任務

提出開發、提交或部署相關的操作需求。

02 / AGENT

Agent 產生意圖

依 Skill 與 Context 規劃下一步，準備 Tool Call。

03 / GATE

執行前檢查

Harness 進入執行層，檢查 Command Policy、Permission 與敏感資料。

04 / DECISION

Allow／Confirm／Deny

低風險操作放行；高風險或不可逆操作要求人工確認；不符合規則則拒絕。

05 / EXECUTE

Tool Execution

在 staging、PAT 與既定權限下執行指令或工具。

06 / OUTPUT

結果與稽核

保留執行結果、錯誤與可追溯記錄，回饋下一次檢查。

Skills描述能力與開發規範。
Harness把安全邊界放到實際執行層。
Human Approval保留不可逆或跨信任邊界的決策。
