## 每場課程資料在哪裡

每場課程位於：

```text
hello-world-notes/session/<日期>/<時間>-<主題>/
```

常見檔案位置：

| 內容 | 位置 | 用途 |
|---|---|---|
| 課程基本資訊與官方簡介 | 各場 `README.md` | 課程名稱、時間、講師、地點與背景 |
| 現場筆記 | 各場 `notes.md` | 實際聽課重點、想法與後續研究 |
| 照片與截圖 | 各場 `assets/` | 課程投影片、架構圖與現場素材 |
| Workshop 實作 | 各場 `dev/` 或 `repo/` | 可執行教材、實驗程式與實作成果 |
| 整體整理 | 根目錄 `SUMMARY.md` | 跨課程的技術觀念、成果與建議 |

不是每場都有實作或照片；以各場實際存在的檔案為準。
