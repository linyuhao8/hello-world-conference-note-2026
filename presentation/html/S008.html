Workshop 產出的部署視角

預購抽選系統如何落在執行環境，並與代理商既有系統協作

01 / 本次系統

新增的預購抽選能力

預購抽選系統由管理後台、預購 API、抽選排程與預購資料庫四個 Container 組成。

02 / 執行責任

Container 對應到部署位置

預購 API → ECS Fargate；抽選排程 → EventBridge 排程任務；預購資料庫 → RDS for PostgreSQL。管理後台由辦公室電腦開啟。

03 / 外部依賴

既有系統不屬於新增邊界

代理商既有實名制 App 負責登入、實名驗證與推播；既有門市取貨系統接收中籤名單與門市選擇。

04 / 資料流

設定 → 登記 → 抽選 → 取貨

營運人員設定活動；App 送出登記；API 保存資料；排程讀取並保存結果；App 推播結果，再將門市選擇送往既有門市系統。

Deployment View ≠ Container View
這是 DSL 的部署映射，不是 AWS Production Runtime 證據；`inspection.error: 8` 的含義仍未確認。
