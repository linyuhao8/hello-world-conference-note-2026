## Slide Copy

### 一個可觀察的 Discovery Sequence

1. `GET /mcp` → `401 Unauthorized` + `WWW-Authenticate`
2. 讀取 Protected Resource Metadata（PRM）
3. 取得 `authorization_servers` 與 `resource`
4. 讀取 issuer 的 Authorization Server metadata
5. 找到 authorization、token、JWKS 與 PKCE `S256` endpoints

Lab 02 的有效 Token 仍回 `401`：這是教學中間狀態，代表本關只驗證 discovery。

- Input：未授權的 MCP request。Processing：依 HTTP challenge 探索資源與授權伺服器。Output：可進入下一關 PKCE 的 endpoints 與 resource context。
