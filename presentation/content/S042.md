## Slide Copy

### 最小行動清單

**可立即驗證**

1. 統一一個 `verify` command，讓 Agent、Git Hook、CI 呼叫同一入口
2. 保存 stdout、stderr、violation path、測試結果與變更 diff
3. 固定 reconciliation 與架構檢查，讓 correctness 不只看單次測試

**需要先研究**

4. 定義 retry budget 與人工接管條件
5. 標記 commit、push、deploy、權限提升等人工核准邊界
6. 再評估 Agent task trace、FinOps allocation 與 MCP revocation
