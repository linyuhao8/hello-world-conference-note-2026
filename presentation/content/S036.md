## Slide Copy

### Planner、Generator、Evaluator 形成回圈

- **Planner**：選 Prompt、Context 與 Tool，定義本輪任務
- **Generator**：執行 orchestration、工具、state 與 memory
- **Evaluator**：讀取 Session、Trace、Span、Metric、Log，執行 schema／test／architecture check
- **Recovery**：依結果 retry、rollback、fallback、skip，或交給 Human Intervention

失敗必須留下可定位的訊號，才能決定下一輪從哪裡恢復。

## Visualization Specification

- 主視覺為 Light Planner → Generator → Evaluator loop，中央以失敗分支連到 Recovery，再回到 Planner 或 Generator。
- Nodes：Planner、Generator、Evaluator、Observability、Verification、Evaluation、Recovery、Human Intervention、Output。
- Relations：Planner → Generator；Generator → Output／Observability；Evaluator 讀取 Session／Trace／Span／Metric／Log 與驗證結果；通過 → Output；失敗 → Recovery；Recovery → retry Generator、rollback、fallback 或 Human Intervention；必要時回 Planner。
- Input：任務、Context、工具與執行狀態。Processing：產生、觀測、驗證、評估、分類失敗。Output：可接受結果、恢復動作或人工接管。
- Failure Path：Tool timeout、schema failure、test failure、architecture check failure 都要有不同證據入口；不把所有失敗壓成單一 `Failed`。
