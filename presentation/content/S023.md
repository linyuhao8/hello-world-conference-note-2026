## Slide Copy

### 一個可重跑的增量迴圈

`需求共識` → `Implementer 實作／測試` → `主 Agent 驗證` → `Atomic Commit` → `Policy／Business Review` → `Human Review`

- 驗證不通過：回到實作，保留失敗原因
- Git Hook 或檢查失敗：修正後重新驗證
- 每個小增量都應能說明：改了什麼、怎麼驗證、為何可以提交

## Visualization Specification

- 主視覺為深色閉環流程圖，左側約 38% 放裁切後 Workshop 照片，右側約 62% 重繪 atomic implementation loop。
- Nodes：Background / Goal / Non-goal / Acceptance Criteria、Meta-Agent、Implementer、Tests、Verification、Atomic Commit、Policy Reviewer、Business Reviewer、Human Review。
- Relations：需求共識 → Meta-Agent 拆單 → Implementer 實作／測試 → Meta-Agent 驗證；通過 → Atomic Commit → Policy Reviewer → Business Reviewer → Human Review；不通過 → 回到 Implementer。
- Input：可驗收的小工作項目與 Acceptance Criteria。Processing：實作、測試、驗證、審查。Output：可追溯的 Atomic Commit 與失敗／修正證據。
- 突出「回到實作」的失敗箭頭與「Atomic Commit」節點，不重新解釋前頁的 Agent 基本定義。
