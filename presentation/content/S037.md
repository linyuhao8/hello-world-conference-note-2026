## Slide Copy

### Rule 不等於 Enforcement

`Prompt／AGENTS.md／Skill` → 說明規則與方向

`Lint／Architecture Test` → 找出違規

`Git Hook／CI／Branch Protection` → 阻止違規變更繼續前進

同一條架構規則，必須從 Agent 的自我檢查一路接到 Repository 的合併門檻。規則仍由人維護，檢查結果才是可執行證據。
