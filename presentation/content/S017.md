## Slide Copy

### 成本治理是一條可追蹤的迴路

`估算需求` → `分配成本` → `監控使用量` → `對照預算` → `分析異常` → `調整資源` → `追蹤結果`

- **Inform**：知道誰用了什麼、用了多少、成本如何累積
- **Optimize**：比較配置、負載與實際消耗，找出可調整處
- **Operate**：把預算告警、資源責任與例外處理放進日常運作

## Visualization Specification

- 主視覺為橫向 FinOps lifecycle，使用照片左側局部作為 Workshop evidence，右側繪製三階段與資料流。
- Nodes：Demand Estimate、Allocation、Usage / Cost Data、Budget、Anomaly、Resource Adjustment、Result Tracking。
- Relations：Demand Estimate → Allocation；Allocation → Usage / Cost Data；Usage / Cost Data ↔ Budget；異常 → Resource Adjustment → Result Tracking → 下一輪估算。
- 三階段分組：Inform = 看見資料，Optimize = 比較與調整，Operate = 持續執行。Input 是需求、資源與預算；Output 是可解釋的成本責任與調整決策。
- 突出「allocation rate」與「consumption rate」是不同觀察角度，但不要在本頁替它們填入未確認的正式定義。
