# S015 — Skill 描述規範，Harness 決定能不能執行

## Slide Metadata

- **Title：** Skill 描述規範，Harness 決定能不能執行
- **Subtitle：** Agent 可以提出意圖，但工具執行仍要經過權限、檢查與人工核准
- **Main Message：** Skills 和 Prompt 提供規範與上下文，Harness、Command Policy、Secret scanning、使用者權限與 staging gate 才能把規範變成執行時的限制。

## Slide Copy

### Soft Constraint

`Prompt → Rules → Skills → Development guidance`

告訴 Agent 應該怎麼做，但模型可能理解錯誤、忽略規則，或執行不預期的操作。

### Enforced Constraint

`Tool Call → Harness → Policy / Secret Check / Permission → Audit`

在工具執行前、執行中與執行後限制實際動作。

### 例：同一個 Tool Call 的三種結果

- **ALLOW：** 低風險、符合分類，照常執行。
- **CONFIRM：** 需要輸入 `DELETE` 或人工核准才放行。
- **DENY：** 風險過高或不符合政策，當場不執行。

規範的責任不只在模型輸出，也在 Tool Call 能不能跨過執行邊界。
