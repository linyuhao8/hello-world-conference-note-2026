## Slide Copy

### 三層責任，避免 Agent 自由猜測

- **Rule Engine**：依告警類型、服務與條件，決定要查什麼
- **Evidence Retrieval**：取得即時 Metrics、Logs、Traces、Events 與設定
- **Agent Explanation**：整理證據、指出未知、提出下一個查詢與結構化結果

歷史事故 Vector Search 可以提供相似案例；最終結論仍需回到本次即時證據與人工確認。

## Visualization Specification

- 主視覺為 Light responsibility map，四段水平流程：deterministic filter → evidence retrieval → explanation → human decision。
- System Boundary：Incident Investigation Pipeline。Components：Alert、Rule Engine、Context Builder、Live Observability Sources、Historical Incident Knowledge Base、SRE Agent、Structured Report、Human Engineer。External Dependencies：Grafana／Loki／Kubernetes 等資料源。
- Relations：Alert → Rule Engine → Context Builder；Context Builder → Live Sources；Historical Knowledge Base → Context Builder（補充）；Context → SRE Agent → Structured Report → Human Engineer。
- Input：原始告警與規則條件。Processing：縮小查詢範圍、取得即時證據、整理歷史參考、產生解釋。Output：附證據來源的報告與人工決策。
- 把 Historical Knowledge Base 畫成虛線輔助支線，避免它看起來能覆蓋即時資料。
