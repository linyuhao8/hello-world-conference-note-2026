## Official Description

2026-10-14 15:15 - 15:45 BC 會議室
SHARE
穩才是快 ～ 以 OKF 打造 Agentic AIOps 治理閉環
摘要
貼一段 log、問 AI「這該怎麼辦」~ 很多人的 AI 維運就停在這。問題是 Agent 每次都從零開始，不懂你的架構，也不記得上週的異動，建議敢放到正式區執行嗎？。本議題將分享在全球規模服務下的嚴謹 AIOps 架構，透過 Google 的 Open Knowledge Format (OKF) 標準，強化 Agent 間的記憶認知。打造一個讓它們看得懂、知道發生什麼、該做什麼、可審核、可稽核的 AIOps 閉環。說明實際落地案例與 FinOps 治理成效。
大綱
1. 全球服務維運的挑戰
2. 以 OKF 標準化 Agent 記憶
3. 建造 Architect / SRE / DB / Audit 四 Agent 團隊
4. 治理觀點～可迭代、可回滾、可稽核的 AIOps 閉環
5. PoC 落地案例、FinOps 治理成效分享
聽眾收穫：
1.「AI 每次都失憶、講不到重點」學會用 OKF 建立 Agent 讀得懂又連貫的記憶框架
2.「不敢讓 AI 真的動手，怕它闖禍」 搭建受理→審核→執行→稽核的閉環。職責分離、出事能回滾，放手也安心
3.「萬一 AI 出包，怎麼救?」做最壞的打算，最好的準備，隔離與驗證該怎麼做
許庭魁 (Jerry Hsu)
華碩電腦 infra Lead
現為華碩電腦資深基礎架構主管，帶領SRE團隊負責華碩電腦官網、AI雲端服務、全球會員系統、資料中台、ROG電競官網...等架構規劃、建置與維運。過去三年，專注於解決複雜的基礎架構需求、安全合規、效能議題，確保全球數千萬用戶能夠穩定且高效地存取華碩電腦提供的數位服務。
同時為台灣SQL PASS社群志工，對SQL效能調教、Azure SQL雲端架構、資料整合方案有興趣。
