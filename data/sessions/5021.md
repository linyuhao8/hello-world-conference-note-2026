## Official Description

2026-10-14 14:15 - 15:00 A 會議室
SHARE
從寫得快到交付可信的 AI Coding 工程戰場
目前前沿的AI Model能力已足以讓 AI Coding Agent 已經能理解需求、修改多個檔案、執行測試，甚至自行完成一項開發任務。但當 AI 產生的程式碼進入到企業專案，必須面對幾個問題：它是否真的跨專案的架構設計？實作上是否符合既有架構或團隊Coding Style？Code Review 是否確實執行？程式碼安全問題是否在建立 Pull Request 前被發現？
因此我想分享在使用SDD進行AI Coding時，能不能再從 Harness Engineering 的角度，實現可落地的 AI Coding 治理架構，過程中將結合VS-Code、Github Copilot、Claude Code Skills 、Rules、Agents 示範如何從 SDD 規格開始，經過 AI 開發、獨立 Code Review、Fortify 常見弱點預檢與程式修正，最後產生一份可以建立 Pull Request 的交付成果。
聽眾收穫：
聽眾將能理解在導入SDD AI Coding再進一步到Skills、Agents、Hooks 各自適合承擔的治理責任，並帶走可以套用到不同 AI Coding 工具與既有專案的架構方法
陳葵懋 (Ian Chen)
一等一科技 研發部主任工程師
任職於一等一科技，同時也是微軟 AI 人工智慧最有價值專家（MVP）與微軟認證講師（MCT）。專注於Azure雲端解決方案、AI、軟體架構與設計，受邀担任公務機關與大學院校AI培訓課程講師、跨國企業AI課程講師，經常於iThome AI & Cloud、Microsoft、Mopcon等研討會分享實務經驗。自2023年起陸續出版多本關於生成式AI與AI Agent的開發書籍，最新一本著作為：AI Agent 奇幻旅程：MCP 通往異世界金鑰。
