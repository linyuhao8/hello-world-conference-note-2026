13:30–15:00｜工作坊時段
AI Agent 在筆電上跑得好好的，搬上雲端卻常常直接設定跑掉，API Key 又怕外流，而且往往當掉卻沒有任何錯誤訊息。這場 workshop 會帶大家五分鐘架好一套跨模型的 AI Native 工作流程，現場示範快速更換 (甚至不用手動更換) provider 而不需改程式邏輯，並用真實案例示範如何用數字而非直覺決定要不要優化，最後講怎麼把這套東西安全部署上雲端。
#Gemini #GoogleDeveloperGroups #GDE #MVP
#AIGateway #MultiModel #CICD #AgentOps #CloudDeployment
課程目標
- 看懂為什麼「跨供應商」是雲端部署的必要條件，不是選配
- 一份可以直接帶回去用的範本，自己接上任一個 LLM provider
- 學會先算數字再優化，不要用直覺決定要不要多寫程式
- 從一台會自己重開機的機器學到的心智模型：本地到雲端，失敗要嘛報錯、要嘛更慘的是不報錯
學員自備裝置

- 事先申請好至少一組 LLM API Key（OpenAI、Gemini 或 Claude 皆可）
學員基礎能力需求
具備基本終端機/命令列操作經驗者體驗較佳(通識級課程,非工程背景亦可參與)
課前準備
提前申請至少一組 LLM Provider 的 API Key(OpenAI、Gemini 或 Claude 皆可),以利現場 Hands-on 操作
