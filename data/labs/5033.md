AI Coding 治理實戰：從開發到交付的Harness工程
13:00–13:30｜環境準備時間
可提早入場準備。
13:25｜正取入場截止／開放備取入場
正取人員請於 13:25 前入場完畢；逾時未入場之名額將釋出，並依備取順序開放入場。
13:30–15:00｜工作坊時段
(本場內容與 10/15 Room 603+604 10:10–12:10 工作坊相同，可依個人時間安排擇一場次參加。)
AI Coding Agent 可以快速完成程式開發，但在實際專案中，團隊仍需要確認實作是否符合需求與架構規範、Code Review 是否確實完成，以及常見安全問題能否在建立 Pull Request 前被發現。
本工作坊將帶領參加者建立一套可實際運作的 AI Coding 本機治理流程。透過SDD 定義功能需求，使用 Skills 封裝開發規範，並建立 Developer、Code Reviewer 與 Security Reviewer 等不同角色的 Agents，實現從寫得快到交付可信任的 Harness Engineering。
課程目標
完成工作坊後，參加者可以體驗到一套可重複使用的 AI Coding 治理範本，包含 SDD 規格、開發與審查 Agents、安全預檢 Skill、Hooks ，可進一步調整並導入到自己或團隊的開發專案。

任職於一等一科技，同時也是微軟 AI 人工智慧最有價值專家（MVP）與微軟認證講師（MCT）。專注於Azure雲端解決方案、AI、軟體架構與設計，受邀担任公務機關與大學院校AI培訓課程講師、跨國企業AI課程講師，經常於iThome AI & Cloud、Microsoft、Mopcon等研討會分享實務經驗。自2023年起陸續出版多本關於生成式AI與AI Agent的開發書籍，最新一本著作為：AI Agent 奇幻旅程：MCP 通往異世界金鑰。
