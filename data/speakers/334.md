## Official Biography

林建宏 (Wolke Lin)
Soho Prompter
林建宏 (Wolke) 是一名專業的軟體開發者與技術講師，曾經同時擁有 Google Developer Expert (GDE) 與 LINE API Expert (LAE) 雙重官方認證。目前在宏國德霖科技大學擔任講師，並活躍於技術教育與開發者社群，曾經為 GDG Taoyuan 的社群組織者。
近年專注於生成式 AI 應用（如 Google Gemini、OpenAI API、Claude）、Vibe Coding 開發模式，以及工作流程自動化（如 n8n、G8N 框架）。致力於降低技術門檻與推廣 AI 工具變現，著有《Gemini 開發實戰全通關》與《Gemini API 開發點子書》等技術專書。
